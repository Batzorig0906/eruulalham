# Эрүүл Алхам — сайтын кодын хавтас

Энэ хавтас нь Танай "Эрүүл Алхам" онлайн дэлгүүрийн бүрэн эх код бөгөөд өөрийн домайн дээр байрлуулахад бэлэн болгосон хувилбар юм. Энэ баримт бичигт: файлуудын тайлбар, GitHub рүү хуулах, үнэгүй хостинг холбох, өөрийн домайн авч холбох, мөн цаашид шинэ бараа хэрхэн нэмэх талаар алхам алхмаар бичсэн.

## Файлууд

- **index.html** — сайтын бүх код (загвар, загварчлал, логик) нэг файлд.
- **products.json** — одоогийн бүх барааны мэдээлэл (нэр, үнэ, размер, нөөц, зураг гэх мэт). Сайт ачаалах үедээ энэ файлыг уншиж бараагаа харуулдаг.

Эдгээр хоёр файл нэг хавтаст, нэг түвшинд байх ёстой (index.html нь `fetch('products.json')` гэж харьцангуй замаар уншдаг тул нэрийг нь бүү өөрчил, байрыг нь бүү шилжүүл).

## 1. VS Code дээр нээх

Энэ хавтсыг компьютер дээрээ хадгалаад, VS Code-оор нээнэ (File → Open Folder…). Локал дээрээ шалгаж үзэхийн тулд `index.html`-г шууд давхар дараад нээж болохгүй (файл систем дээрээс `fetch()`-ээр JSON уншихыг зарим хөтөч блоклодог тул бараа харагдахгүй байж болно). Үүний оронд:

1. VS Code дээр **Live Server** өргөтгөл суулгана (Extensions хэсэгт "Live Server" гэж хайна, Ritwick Dey-ийн).
2. `index.html` файл дээр хулганы баруун товчийг дараад **"Open with Live Server"** гэдгийг сонгоно.
3. Хөтөч автоматаар нээгдэж, сайт локал сервертэйгээр зөв ажиллана.

## 2. GitHub дээр байршуулах

Хэрвээ GitHub бүртгэлгүй бол [github.com](https://github.com) дээр үнэгүй бүртгэл үүсгэнэ. Дараа нь:

1. GitHub дээр шинэ repository үүсгэнэ (жишээ нь `eruul-alkham`), **Private эсвэл Public** — аль ч байж болно.
2. VS Code-ийн доtorolд Terminal нээгээд (Terminal → New Terminal), энэ хавтсанд дараах командуудыг ажиллуулна (`<таны-github-хэрэглэгчийн-нэр>`-г өөрийнхөөр солино уу):

```
git init
git add .
git commit -m "Анхны хувилбар"
git branch -M main
git remote add origin https://github.com/<таны-github-хэрэглэгчийн-нэр>/eruul-alkham.git
git push -u origin main
```

Хэрвээ `git` командыг компьютерт тань анх удаа ашиглаж байгаа бол эхлээд [git-scm.com](https://git-scm.com/downloads)-с суулгах шаардлагатай.

## 3. Үнэгүй хостинг холбох (Netlify)

Static сайтыг үнэгүй, өөрийн домайнтайгаар байршуулах хамгийн энгийн арга бол **Netlify** (эсвэл өөр сонголт болгож **Cloudflare Pages**). Бизнесийн зориулалттай сайтад Netlify болон Cloudflare Pages хоёулаа үнэгүй тарифаараа ашиглаж болно (Vercel-ийн үнэгүй тариф зөвхөн хувийн, арилжааны бус ашиглалтад зориулагдсан тул санал болгохгүй байна).

1. [netlify.com](https://www.netlify.com) дээр GitHub бүртгэлээрээ нэвтэрнэ.
2. **"Add new site" → "Import an existing project"** дараад GitHub repo-гоо сонгоно.
3. Build тохиргоо асуухад юу ч бичихгүй хоосон орхиод ("Build command" хоосон, "Publish directory" `.` буюу root) **Deploy** дарна.
4. Хэдхэн секундын дараа `https://random-name-123.netlify.app` шиг холбоос өгнө — энэ бол Танай сайтын одоогийн шууд холбоос.

## 4. Домайн нэр авах

Танд хоёр үндсэн сонголт байна:

**А) `.mn` домайн** (жишээ: `eruulalkham.mn`) — Монголд бүртгэгддэг нутгийн домайн, Datacom компани удирддаг. Иргэншил/байгууллагын хязгаарлалтгүй, хэн ч бүртгэж болно. Олон улсын бүртгэгчдээр (жишээ нь [Sav](https://sav.com), Instra, 101domain, Asia Registry) авахад жилд ойролцоогоор **$37–$95 орчим** байна — бүртгэгч бүрээр ялгаатай тул хэдэн газраас үнээ харьцуулаад авахыг зөвлөж байна.

**Б) Ердийн олон улсын домайн** (`.com`, `.shop`, `.store` гэх мэт) — Namecheap, GoDaddy зэрэг газраас жилд ойролцоогоор **$10–20 орчим**-оор авах боломжтой, хямд бөгөөд хурдан бүртгэгддэг. Хэрвээ зардлаа хямдруулах хүсэлтэй бол энэ нь илүү дэвшилтэт сонголт.

Домайноо авсны дараа Netlify дээр холбоно:

1. Netlify дээрх сайтынхаа **Site configuration → Domain management → Add a domain** руу орно.
2. Домайныхаа нэрийг оруулна.
3. Netlify танд DNS тохиргооны заавар өгнө — ихэвчлэн эсвэл (а) Netlify-ийн nameserver-үүд рүү домайноо бүрэн шилжүүлэх, эсвэл (б) домайн бүртгэгчийнхээ DNS хэсэгт нэг CNAME/A мөр нэмэх хоёрын аль нэгийг санал болгоно. Зааврыг нь дагаад бүртгэгчийнхээ (Sav, Namecheap гэх мэт) DNS удирдлагад очиж нэмнэ.
4. DNS шинэчлэгдэхэд ихэвчлэн хэдэн минутаас 24 цаг хүртэл (ховор тохиолдолд 48 цаг) болдог. Netlify танай домайныг баталгаажуулмагц **автоматаар үнэгүй HTTPS (SSL) сертификат** олгож, сайт `https://` -ээр найдвартай ажиллана.

## 5. Аюулгүй байдлын талаар

Энэ бүтэц дараах шалтгаанаар өмнөх claude.ai дээрх хувилбараас ч, ер нь ихэнх жижиг дэлгүүрийн сайтуудаас ч аюулгүй байдлын үүднээс энгийн бөгөөд бат:

- Сайт нь **бэкенд/өгөгдлийн сан огт ашигладаггүй цэвэр статик файл** тул хакердах боломжтой нэвтрэлт, нууц үг, серверийн эмзэг цэг гэж байхгүй.
- Захиалгын түүх бүрэн **хэрэглэгчийн өөрийнх нь хөтчинд (localStorage)** хадгалагддаг — ямар ч серверт илгээгддэггүй тул алдагдах, чөлөөтэй унших эрсдэлгүй.
- Netlify/Cloudflare Pages бүгд **автомат үнэгүй HTTPS** өгдөг тул хэрэглэгчийн хөтчид "Найдвартай" гэсэн цоожны тэмдэг харагдана.
- Удирдах самбар (бараа нэмэх/засах) нь одоо зөвхөн **Танай өөрийн компьютер дээр products.json файл татаж авдаг** тул хэн ч нээж үзсэн ч Танай жинхэнэ сайтад нөлөөлөх боломжгүй — зөвхөн Та өөрөө татсан файлаа GitHub рүү push хийж байж жинхэнэ сайт шинэчлэгддэг.

## 6. Шинэ бараа хэрхэн нэмэх вэ (цаашид)

1. Сайтаа нээгээд, доод хэсгийн **"Дэлгүүр эзэмшигч үү?"** холбоос дээр дарж удирдах самбарт орно.
2. **"+ Шинэ бүтээгдэхүүн"** дараад нэр, ангилал, үнэ, өнгө, зураг, размер тус бүрийн нөөц зэргийг бөглөнө.
3. **"Нэмэх"** дарахад хөтөч тань шинэчилсэн **products.json** файлыг автоматаар татаж авна (ихэвчлэн "Downloads" хавтас руу орно).
4. Татсан файлаа хуулж аваад, энэ төслийн хавтас дахь хуучин `products.json`-той **соливол** (overwrite).
5. VS Code-ийн Terminal-д дараах командуудыг ажиллуулна:

```
git add products.json
git commit -m "Шинэ бараа нэмэв"
git push
```

6. Netlify автоматаар шинэ хувилбарыг илрүүлж, ~30 секундын дотор жинхэнэ сайтыг шинэчилнэ.

## Одоогийн claude.ai хувилбарын тухай

Танай claude.ai дээр нийтэлсэн хуучин хувилбар (`claude.ai/code/artifact/...` холбоостой) хэвээрээ ажиллаж байгаа бөгөөд түүн дээрх удирдах самбар claude.ai-д шууд хадгалдаг хэвээрээ байна. Гэхдээ ЭНЭ хавтас дахь кодыг өөрийн домайн дээр байршуулснаар танд **хоёр тусдаа хувилбар** үүснэ — тэдгээр хоорондоо автоматаар синк хийхгүй тул аль нэгийг нь "жинхэнэ" сайтаараа сонгоод, цаашид зөвхөн түүгээрээ ажиллахыг санал болгож байна.
